# PLAN-001 — MVP Improvements

Status: Active

Priority: High

Goal: Transform the current MVP from a content reader into a daily Islamic companion that encourages users to return every day.

---

# Current State

The MVP successfully validates the basic user flow.

Current Flow:

Welcome

↓

Setup

↓

Home

↓

Journey

↓

Completion

The application is simple, focused and distraction-free.

The next iteration should improve the emotional experience instead of adding many features.

---

# Product Goal

The application should answer this question every day:

"Why should I open the app today?"

The answer should never be:

"To read an article."

The answer should become:

"To spend 10 meaningful minutes learning from Islam and applying one lesson today."

---

# Priority 1 — Strengthen Home Screen ´[done]

Current

Home only displays today's journey.

Improve

Home should create anticipation before the journey starts.

Suggested content:

* Journey title
* Category
* Estimated reading time
* Short inspirational subtitle
* Begin Journey CTA

Example

Today's Journey

The Strength of Gratitude

5 min

Today's lesson:

"Small acts of gratitude transform the heart."

[ Begin Journey ]

Expected Result

Increase motivation before entering the journey.

---

# Priority 2 — Journey Progress ´[done]

Current

Journey feels like a long article.

Improve

Split the journey into clear steps.

Example

Story

↓

Lessons

↓

Reflection

↓

Today's Action

Each section should display progress.

Example

Step 1 / 4

Step 2 / 4

Step 3 / 4

Step 4 / 4

Expected Result

Increase completion rate.

Reduce reading fatigue.

---

# Priority 3 — Today's Action ´[done]

Priority: Critical

Every journey MUST finish with one practical action.

Examples

"Call your parents today."

"Express gratitude to one person."

"Read Surah Al-Ikhlas before sleeping."

"Help someone without expecting anything."

Requirements

* One action only.
* Action must be realistic.
* Action must be achievable today.
* Action must reinforce today's lesson.

Expected Result

The application influences real life instead of only delivering information.

---

# Priority 4 — Completion Experience

Current

Journey ends.

Improve

Celebrate consistency.

Suggested completion screen

Alhamdulillah

You invested 10 meaningful minutes today.

May Allah reward your effort.

We'll prepare another journey tomorrow.

Primary CTA

Done

Expected Result

Create emotional satisfaction.

---

# Priority 5 — Build Anticipation ´[done]

After finishing today's journey

Show tomorrow's journey preview.

Example

Tomorrow

Story of Umar ibn Al-Khattab

Available Tomorrow

Do not lock content aggressively.

Simply create curiosity.

Expected Result

Increase next-day retention.

---

# Priority 6 — Weekly Progress ´[done]

Instead of streaks

Display a calm weekly journey tracker.

Example

Monday ✓

Tuesday ✓

Wednesday ○

Thursday ○

Friday ○

Avoid guilt.

No punishment.

No gamification.

Expected Result

Encourage consistency.

---

# Priority 7 — Content Quality

Content becomes the primary competitive advantage.

Every journey MUST contain:

1. Title

2. Introduction

3. Story

4. Key Lessons

5. Reflection Question

6. Today's Action

7. References

Requirements

* Authentic
* Practical
* Easy to understand
* Approximately 5–10 minutes

---

# Priority 8 — Visual Identity

Current UI is clean.

Improve by introducing:

* One hero illustration per journey
* Calm imagery
* Consistent spacing
* Better typography hierarchy

Avoid excessive decoration.

---

# Future Features (Not MVP)

* Notifications
* Search
* Categories
* Bookmarks
* Favorites
* AI Recommendations
* Audio
* Offline Downloads
* Achievements
* Personalization

Do NOT implement these during MVP validation.

---

# Success Metrics

Primary

* User returns tomorrow.

Secondary

* Journey completion rate.
* Time spent reading.
* Daily active users.
* Reflection completion.

---

# Product Principle

Every new feature should answer:

"Will this increase the likelihood that the user returns tomorrow for another meaningful journey?"

If the answer is NO,

do not implement it.

---

# Implementation Instructions

You are responsible for improving the existing MVP.

Goals

* Improve user retention.
* Improve emotional connection.
* Improve journey completion.
* Preserve simplicity.
* Preserve minimalism.

Avoid

* Feature bloat.
* Complex navigation.
* Multiple CTAs.
* Social features.
* Gamification.

Focus on habit formation through meaningful daily learning.

Implement improvements incrementally.

After each improvement, explain:

* Why the change improves the product.
* Expected UX impact.
* Potential risks.
* Alternative approaches if applicable.
